# Contributing

GPX Viewer is a personal, non-commercial project by A097MPRUS. Problem reports and suggestions are welcome through the issue templates or SourceForge tickets.

- This repository contains documentation and release metadata only. `README.md` sections between `<!-- ... -->` markers, `CHANGELOG.md` and `docs/FEATURES.md` are generated from `release/*.json` by `node scripts/generate.mjs`; edit the JSON in the application project instead.
- Write plain, factual English without em or en dashes.
- Never include private GPS recordings, health data, API keys or personal information in issues or pull requests.
- Contributions are accepted under the MIT License.
